feat(xtask): migrate from Just to xtask build automation (Phases 1-7)

Migrate BDP's build automation from Just (external tool, 810-line shell script)
to xtask (Rust-native pattern), converting 95 justfile recipes into 103 type-safe
Rust commands organized across 16 specialized modules.

## Key Changes

### Core Implementation
- Created 16 xtask modules (~65.5 KB Rust code, 103 commands)
  - Database (db), Development (dev), Testing (test), Build (build)
  - Docker, SQLx, MinIO, Ingestion, CI, Cleanup, Documentation
  - Setup, Infrastructure, E2E, Release, Utilities
- Implemented utils.rs with 20+ helper functions
- Cross-platform support (Windows PowerShell + Unix Bash)
- Colored terminal output for better UX

### CI/CD Updates
- Updated .github/workflows/ci.yml to use cargo xtask
- Removed 6 setup-just@v3 action steps (faster CI)
- Updated 6 command invocations (lint, test, sqlx-check, builds)

### Documentation
- Updated critical docs: CLAUDE.md, README.md, CONTRIBUTING.md, SETUP.md
- Created comprehensive guides:
  - xtask-guide.md (1,000+ lines) - Complete usage guide
  - xtask-command-reference.md - Quick reference
  - migration-complete-checklist.md - Testing checklist
  - just-references-summary.md - Remaining work catalog

### Cleanup
- Archived STREAMING_IMPLEMENTATION_COMPLETE.md
- Archived DEPLOYMENT_READY.md
- Added deprecation notice to justfile

## Benefits

- ✅ Type-safe: Tasks are compiled Rust code
- ✅ No installation: Uses existing Cargo toolchain
- ✅ Better DX: Full IDE support (autocomplete, refactoring)
- ✅ Maintainable: 16 logical modules vs. 810-line flat file
- ✅ Community standard: Used by rust-analyzer, cargo, ripgrep

## Command Migration Examples

- `just dev` → `cargo xtask dev server`
- `just test` → `cargo xtask test all`
- `just db-migrate` → `cargo xtask db migrate`
- `just lint` → `cargo xtask dev lint`
